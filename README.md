# Convite de Formatura

Convite digital responsivo para a colação de grau da Bruna, em 19 de agosto de 2026.

## Desenvolvimento

```bash
npm install
npm run dev
```

## Publicação na Cloudflare

O projeto é compilado como Cloudflare Worker com assets estáticos.

```bash
npm run deploy
```

Ao conectar este repositório à Cloudflare, use `npm run deploy` como comando de implantação.
